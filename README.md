# Arsen Arn
### Game Producer · Senior Game Designer · AI-Assisted Prototyping

Based in Vilnius, Lithuania · Open to remote work and relocation

I have 8 years of experience in mobile F2P games across casual, hybrid-casual, puzzle, and arcade genres. I have worked on **12 commercial releases with 40M+ combined installs**, including **10 as Producer**.

Alongside commercial work, I've built **16 playable personal game prototypes** using AI-assisted workflows: **13 mini-games in one collection** plus **3 standalone projects** highlighted below. My background is primarily in game design and production; I use AI-assisted development to turn concepts into playable builds quickly.
